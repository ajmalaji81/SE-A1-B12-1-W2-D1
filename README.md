# 🥗 Clinical South Indian Nutrition Protocols

Print-ready, evidence-based 7-day vegetarian and non-vegetarian South Indian meal plans engineered for two distinct metabolic profiles:
1. **Caloric Surplus & Hypertrophy** (Adults in their 30s)
2. **Caloric Deficit & Sarcopenia Defense** (Seniors in their 60s)

---

## 📋 Overview & Clinical Targets

| Metric | Phase I: Weight Gain (Age 30s) | Phase II: Weight Loss (Age 60s) |
| :--- | :--- | :--- |
| **Primary Goal** | Lean muscle mass & metabolic surplus | Visceral fat loss & lean mass retention |
| **Caloric Range** | 2,600 – 2,800 kcal / day | 1,400 – 1,550 kcal / day |
| **Target Protein**| 125g – 140g (~1.8g/kg) | 75g – 85g (~1.2g/kg) |
| **Fiber / Sodium**| High complex carbohydrate pacing | 30g+ soluble fiber; <1,500mg daily sodium |
| **Track Coverage**| Vegetarian, Non-Vegetarian, Hybrid | Vegetarian, Non-Vegetarian, Hybrid |

---

## 📂 Included Documents

- **`weight_gain_meal_plan_30s.html`**  
  2-page printable layout featuring a structured tabular chart (Breakfast, Mid-Morning, Lunch, Evening Snack, Dinner) covering days 1–7, nutrient breakdown, vegetarian protein pairing matrix, and recovery sleep guidelines.
  
- **`weight_loss_meal_plan_60s.html`**  
  2-page printable layout featuring early dinner scheduling, split-pulse digestion strategies, cardiovascular sodium limits, and sarcopenia prevention guidelines for older adults.

## 🖨️ How to Export as PDF

Both HTML files are formatted to print directly to standard **A4 paper** with clean page breaks and zero layout shifts:

1. Open either `.html` file in any modern web browser (Google Chrome, Edge, Safari, Brave).
2. Press `Ctrl + P` (Windows/Linux) or `Cmd + P` (macOS).
3. Set **Destination** to `Save as PDF`.
4. Set **Paper Size** to `A4`.
5. Set **Margins** to `None` or `Default`.
6. Enable **Background graphics** under print options.
7. Click **Save**.
